# Звёздная гонка

Веб-приложение: твой путь с 18 лет — звезда рядом со средним человеком страны, верхними 10% и друзьями.

## Как запустить на компьютере с Windows — пошагово

### Шаг 1. Проверить, что установлен Node.js
1. Нажми клавишу **Win**, набери `cmd` и нажми **Enter**. Откроется чёрное окно «Командная строка».
2. Вставь в него команду `node -v` и нажми **Enter**.
3. На экране должна появиться версия, например `v24.22.0`. Подойдёт любая версия от 20 и выше.
4. **Если появилось «node не является внутренней или внешней командой»** — скачай Node.js LTS с сайта
   https://nodejs.org, установи с настройками по умолчанию, закрой и снова открой командную строку и повтори пункт 2.

### Шаг 2. Перейти в папку проекта
1. В том же окне вставь команду (путь замени, если папка лежит в другом месте):
   `cd %USERPROFILE%\Projects\star-race`
2. Нажми **Enter**. Строка ввода начнётся с этого пути.
3. **Если пишет «Системе не удаётся найти указанный путь»** — открой папку проекта в Проводнике,
   щёлкни по адресной строке вверху, скопируй путь и выполни `cd "вставленный путь"`.

### Шаг 3. Установить зависимости (один раз)
1. Вставь `npm install` и нажми **Enter**.
2. Подожди 1–3 минуты. В конце появится строка вида `added 400 packages` и `found 0 vulnerabilities`.
3. **Если появились красные строки `ERR!`** — проверь интернет и повтори команду. Не помогло — скопируй
   текст ошибки и пришли Claude.

### Шаг 4. Запустить сайт
1. Вставь `npm run dev` и нажми **Enter**.
2. Через несколько секунд появится строка `Local: http://localhost:3000`.
3. Открой браузер и перейди по адресу **http://localhost:3000** — откроется «Звёздная гонка».
4. Чтобы остановить сайт, вернись в чёрное окно и нажми **Ctrl + C**.

### Шаг 5. Продолжить разработку с ИИ-командой
1. Открой приложение **Claude** на компьютере и перейди на вкладку **Code**.
2. Выбери папку `star-race` как рабочую.
3. Напиши задачу, например: «T-01, возьми пункт 1 из бэклога в CLAUDE.md». Правила команды Claude
   прочитает из файла `CLAUDE.md` сам.

## Интернет: Vercel + Supabase + Telegram

- Короткие ссылки `сайт/?s=abc1234` хранятся в Supabase (проект «KIMDMITRIY92's Project», таблица `star_links`,
  доступ только через функции `star_link_create` и `star_link_get`). В таблице только код звезды — уровни, без сумм дохода.
- Переменные Vercel (Settings → Environment Variables), необязательные — есть значения по умолчанию:
  `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_KEY` (publishable), `NEXT_PUBLIC_TG_APP` (например `https://t.me/StarRaceBot/race`).
- Telegram Mini App: бот через @BotFather → `/newapp` → адрес сайта на Vercel. Приглашение внутри Telegram —
  `https://t.me/<бот>/<app>?startapp=<id>`.

## Полезные команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Запускает сайт на http://localhost:3000 |
| `npm test` | Проверяет расчёты (должно быть «passed») |
| `npm run build` | Собирает сайт для публикации |
| `npm run build:standalone` | Собирает один файл `dist/star-race.html` — открывается двойным щелчком без сервера |
